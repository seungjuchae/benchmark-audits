왜 문제인가

어떤 조합을 “하나의 검사”로 인정할지 표준 목록이 없습니다. API 오류가 아니라 정상 응답 본문으로 프롬프트의 거부 문구가 반환됐지만, 구체적인 거부 이유는 적혀 있지 않습니다.

판정: 요청 표현과 검사 단위 해석에 민감하다는 근거입니다. “단일 시술의 부속 검사” 또는 “명명된 패널”은 허용하고 독립 검사 병합은 거부했을 가능성이 있어, 모순이나 명백한 규칙 위반이라고 단정할 수 없습니다.

실험 한계: 검사 분할과 호출당 요청 수를 동시에 변경했습니다. 원래 묶음을 그대로 한 호출씩 보낸 대조군은 없으므로, 두 요인의 영향을 분리하지 못했습니다. 각 조건은 1회 관측입니다.
