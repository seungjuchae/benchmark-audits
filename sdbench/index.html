SDBench

Our audit of Microsoft SDBench on one synthetic case (case 0). It covers two observed diagnostic runs, GPT-5 and Astra max, which a GPT-5 Judge scored 4/5 each. It also covers a replay of the GPT-5 run’s test requests through an Astra Gatekeeper, two Judge probes we constructed, and an estimated cost comparison. Start with the case 0 audit or the summary brief. Most of the detailed reports are in Korean.

How to read these

Observed runs are real SDBench runs. Gatekeeper replays resend saved requests to a different Gatekeeper without continuing the diagnosis or calling the Judge. Judge probes use answers we wrote ourselves, so they test the scorer, not a model’s behavior.

Evidence files (JSON logs, rubrics, fixtures) sit next to the page that cites them. Links to SDBench source code point to microsoft/sdbench at commit 304ce96.
